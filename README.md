# Crew Task Allocation System for Airline Operations using Random Forest: A Case Study of Kenya Airways

## 1.Project Overview

Airline crew allocation involves assigning qualified crew members to flights while considering qualifications, availability, duty-hour limits, rest periods and operational requirements. Flight disruptions, crew shortages and schedule changes make this process increasingly complex.

This project develops an AI-assisted crew task allocation system that uses machine learning to recommend suitable crew members and support airline operational decision-making.

The system is an academic prototype developed using synthetic crew allocation data. It is not an officially deployed Kenya Airways system.

## 2. Key Features

* Firebase authentication and role-based access.
* Separate interfaces for Flight Crew, Crew Controllers, and Managers.
* Crew schedule and availability management.
* AI-based crew recommendations using a Random Forest model.
* Eligibility filtering based on predefined operational constraints.
* Cloud-based data storage using Firebase Firestore.
* REST API integration for machine learning recommendations.
